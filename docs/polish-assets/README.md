# One Move Puzzle — Code-ready Polish Assets

41 transparent PNG assets, individually cropped and QA-checked.

- `assets/interaction/`: pin / goal / star / button states
- `assets/fx/`: click / glow / burst / spark / dust / trail
- `assets/ui/`: logo / buttons / panels / toggles / HUD
- `src/polishAssets.js`: Vite `import.meta.glob` asset map
- `manifest.json`: asset paths and dimensions
- `preview/contact-sheet.png`: checkerboard transparency preview

Copy `assets/` and `src/polishAssets.js` into the game project.
